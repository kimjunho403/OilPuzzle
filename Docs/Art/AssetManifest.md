# 마라탕 에셋 분석 — 예상 화면 검토 후 확정

참조: `Concepts/Mala-Target-v01.png` (AI가 생성한 비주얼 목표, 실제 실행 화면 아님).

**0.2 변경:** 아래 목록의 다섯 이미지를 캐주얼 일러스트로 다시 생성했다. 현재 적용된 프롬프트는 `Casual-v02-prompts.md`, 실제 화면은 `ActualGame-Casual-v02.png`이다. 이전 컨셉과 개별 `.prompt.txt`는 최초 제작 이력이다.

## 화면에서 유지할 요소

아이보리 식탁·도자기와 진한 붉은 국물의 대비, 얇게 반짝이는 황금색 고추기름, 표고버섯과 완자, 옥색 목표 원, 담백한 한국어 HUD.

컨셉에는 재료와 잔기름이 많다. 실제 게임은 터치 표면과 통로를 명확히 읽을 수 있도록 국물 중앙을 비우고, 모든 충돌 재료를 독립 오브젝트로 배치한다. 그릇은 원형으로 완전히 화면 안에 들어오게 한다. 이미지에 생성된 문구는 실제 UI로 다시 구현한다.

## 생성할 래스터 이미지

| 파일 | 내용 | 배경 | 사용 |
|---|---|---|---|
| Table.png | 세로 아이보리 식탁, 가장자리만 소량 향신료와 린넨 | 불투명 | 전체 화면 바탕 |
| BowlBroth.png | 정탑뷰 원형 도자기 그릇과 비워둔 적갈색 국물 | 바깥 투명 | 플레이 영역 바탕 |
| Shiitake.png | 별 모양 칼집 표고버섯 한 개, 원형 상면 | 투명 | 원형 장애물 |
| FishBall.png | 고추가 조금 묻은 밝은 완자 한 개 | 투명 | 원형 장애물 변형 |

모든 이미지의 광원은 왼쪽 위, 실사 재질을 단순화한 고급 음식 게임 아트. 원본 생성물을 저장하고 Unity import 설정으로 크기와 압축을 조정한다. 런타임 이미지 수정은 필요하지 않다.

## 이미지로 만들지 않는 요소

| 요소 | 방식 | 이유 |
|---|---|---|
| 기름 덩어리 | 입자 밀도장 + 커스텀 셰이더 | 클릭 지점 변형과 분열을 연속적으로 표현 |
| 목표 링·손끝 링 | 동적 선/원 메시 | 크기·진행도와 선명도 유지 |
| 버튼·장력 게이지·스테이지 | Unity UI + 단순 기하 | 해상도 대응, 한국어 현지화 |
| UI 텍스트 | 번들 한국어 폰트 | 생성 이미지 글씨에 의존하지 않음 |
| 충돌 | 원형 기하 데이터 | 스킨이 바뀌어도 규칙 일관 |

## 비이미지 에셋

- Mala SoupSkin ScriptableObject 1개.
- StageDefinition 5개 및 플레이 씬 1개.
- 밀도 누적/표면 합성 셰이더, 재질.
- 터치와 마우스 입력 컨트롤러, 국소 드래그 시뮬레이션, HUD.
- 라이선스 확인 가능한 한국어 폰트. Windows 시스템 글꼴은 게임 배포용으로 복사하지 않는다.
- 검증 테스트 및 실제 Unity 렌더 캡처.

## 생성 이력

생성 방식: built-in image_gen. 개별 프롬프트는 이 폴더의 `*.prompt.txt`에 기록. 생성 결과는 `Assets/Oilpuz/Art/Mala`에 복사하며, 사용하지 않는 컨셉은 빌드에 포함하지 않는다.
